# NOVERA ROBOTICS

Independent concept-stage humanoid robotics startup website, separate from VELTARO.

## Website

Open `index.html` in any browser. This is a dependency-free bilingual Greek/English responsive static website.

## GitHub Pages

In GitHub, open **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/ (root)`, then Save. Publication can take a few minutes. Expected project URL after successful deployment: `https://panagiotagrosdouli.github.io/NOVERA/`.

## Notes

NOVERA ONE is a concept, not a built or certified humanoid robot. Images are third-party reference imagery, not product photographs. Emotion-aware interaction does not imply real feelings or consciousness. The contact form is demonstrative and does not transmit or store personal data. Obtain suitable imagery rights, domain/trademark clearance, and implement real form handling and privacy materials before commercial launch.
