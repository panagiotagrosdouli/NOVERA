# Roadmap: concept to evaluated prototype

| Gate | Deliverable | Exit criterion |
|---|---|---|
| G0 — Scope | V1 use case, requirements, excluded functions | Written acceptance |
| G1 — Feasibility | 3 CAD envelope alternatives, mass/power estimates, safety concept | Technical review |
| G2 — Architecture | Schematics, subsystem interfaces, initial component shortlist | Requirements traceability |
| G3 — Simulation | Mobility/controller simulations, failure cases | Reproducible results |
| G4 — Bench | Low-level controller and drivetrain bench demonstrator | Safe-stop tests passed |
| G5 — Prototype | Mechanically integrated indoor demonstrator | Controlled testing completed |
| G6 — Validation | Usability, safety, reliability, privacy checks | Independent documented review |

**Now:** G0/G1 planning only. The website demos and concept renders are not evidence of G4–G6 achievement. No supplier outreach or expenditure is authorized.
