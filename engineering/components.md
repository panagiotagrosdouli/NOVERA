# Initial trade study — no purchasing decision

| Subsystem | Candidates to evaluate | Key selection criteria |
|---|---|---|
| Drivetrain | Differential two powered wheels + casters; omnidirectional alternative | Maneuverability, stability, stopping distance, control complexity |
| Computer | Embedded x86 mini-PC; ARM edge computer | Power, thermals, local processing, serviceability |
| Motion controller | Microcontroller with monitored watchdog | Predictable behavior, isolation from high-level application |
| Localization | 2D lidar + odometry; depth camera fusion | Lighting dependence, glass issues, indoor reliability, privacy |
| Human interface | Screen + speakers + optional microphones | Accessibility, offline mode, clear consent state |
| Battery | Certified commercial battery/BMS solution | Electrical safety, service access, thermal risk, lifecycle |
| Mechanical | Sheet-metal internal frame + designed covers | Tip stability, cable routing, maintainability, guarding |

Do not interpret this as a confirmed bill of materials, exact supplier list, validated design, or budget quote. Estimate costs only after sourcing datasheets and agreeing on a prototype boundary.
