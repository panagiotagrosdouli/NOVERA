# NOVERA ONE V1 — Draft requirements (v0.1)

| ID | Requirement | Proposed acceptance check | Status |
|---|---|---|---|
| R-01 | Indoor, level-floor mobility only | Define test floor, door clearances and obstacles; demonstrate safe maneuvering | Proposed |
| R-02 | Emergency stop independent of application logic | Verify motor power is disabled by physical stop and remains disabled until reset | Proposed |
| R-03 | User-controlled, clear listening/camera indicators | Inspect visible state, explicit permissions and camera/microphone disablement | Proposed |
| R-04 | Remote or local supervised operation as fallback | Demonstrate operator override and safe stop on loss of link | Proposed |
| R-05 | Bilingual Greek/English interface | Task-based interaction walkthrough in both languages | Proposed |
| R-06 | Conservative speeds in occupied spaces | Set limit after hazard analysis; test in controlled environment | Proposed |
| R-07 | Low battery and communication failures lead to safe state | Fault-injection test; no unintended travel | Proposed |
| R-08 | Accessible interaction modes | Evaluate touch, text, auditory and low-stimulation interaction with users | Proposed |
| R-09 | Stable base against tipping | Check center of mass and stability for planned payload and maneuvers | Proposed |
| R-10 | Data minimization, consent and deletion | Document data flows; verify deletion and retention settings | Proposed |

**Initial envelope to investigate, not a finished specification:** height ~0.9–1.2 m; width ~0.4–0.6 m; indoor wheeled base; payload and mass TBD. All dimensions are placeholders for first CAD studies.

Out of scope for V1: stair climbing, human lifting, clinical diagnosis, unattended child supervision, emergency response, industrial load handling.
